# Contributing

Propose a specific user problem and the evidence needed to verify it. Keep skills focused, preserve user authorization, and avoid presenting model judgments as user research. Changes to third-party references should record provenance and applicable licensing.

Run `python3 -m unittest discover -s tests -v` before submitting. These checks verify package structure and routing instructions; they do not prove an agent chose or executed a skill. For behavioral changes, document the host, prompt, available skills, observed route, relevant output, and untested cases. Never include private project data or credentials in an issue or test fixture.
