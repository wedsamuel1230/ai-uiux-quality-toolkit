# Supplied Visual and Component Resource Catalog

These links come from two user-supplied posts by Dreameryanyan (`@yanliudreamer`): [10 inspiration sites, October 15, 2026](https://x.com/yanliudreamer/status/2110649301257060368) and [10 UI resources, October 22, 2026](https://x.com/yanliudreamer/status/2113188741452103685). The post descriptions are recommendations, not independently audited findings. Recheck availability, access, pricing, accessibility, licensing, and product scope at point of use. `Mobbin` and `Lapa Ninja` already appeared in the V3 reference index; that index lists them as study targets, not observed product evidence.

## How to use a reference responsibly

1. State the design question before browsing.
2. Select one or two references that answer that question.
3. Record the exact page/flow, date, platform, access context, and what was actually observed.
4. Translate the observation into a hypothesis and test it against the current users, task, platform, design system, and accessibility needs.
5. Check asset/code rights before shipping. Do not copy distinctive layouts, brand assets, illustrations, or code by default.
