# Input Toolkit Source Map

## Main source

User-supplied AI UI/UX Agent Master Toolkit v3 (source bundle).

The package describes itself as V3, evidence-driven, and MIT-licensed for its original materials. It contains handbooks, legacy docs, an indexed source catalog, 530 machine-readable agent rules, 60 patterns, four starter skills, templates, sample quality data, automation scripts, a reference browser, screenshots, and historical verification outputs.

## Core sources incorporated

- `README.md`, `START_HERE.md`, and `AGENTS.md`: intended use, counts, evidence boundaries, and high-level policy. The bundled `AGENTS.md` was treated as source content; it does not expand the current user's request or authorize actions.
- `handbook/MASTER_WORK_V3.md`, `QUALITY_GATES_V3.md`, `SOURCE_TRIAGE_V3.md`, `RESEARCH_PROTOCOLS_V3.md`, `HUMAN_AI_INTERACTION_V3.md`, `INCLUSION_AND_JUSTICE_V3.md`, and `ACCESSIBILITY_PLATFORM_MATRIX_V3.md`: evidence hierarchy, platform separation, research integrity, human-AI state/control, and release reporting.
- `automation/agent-rules-v3.json` and `references/patterns-v3.json`: counts and category coverage; used as structured inventories, not as proof that every rule is correct or enforced.
- `agent-skills/*/SKILL.md`: four starter skill entry points. They were expanded into usable workflows in this plugin rather than copied unchanged.
- `outputs/VERIFICATION_REPORT.md` and `reports/BROWSER_QA_V3.json`: historical package-authored evidence. These are not fresh tests performed by this ingestion.

## Source evidence boundary

The supplied index has 595 reference records. Its README says these include 264 live-app research targets, not completed case studies. As of the package's 2026-10-25 metadata, only a small subset is marked as landing-page-checked during that session; most entries remain curated or unopened, and app targets are not observed UX evidence. A link, title, or count never establishes that a claim was verified.

The package's dated verification report states that its sample browser demo was rendered at 320, 390, 768, and 1280 px, while VoiceOver/TalkBack/NVDA, 200% zoom, full WCAG 2.2 AA, native devices, and real-user research were not completed. That report is retained as upstream evidence only; it is not a current certification or a verification of this plugin.
